# arc-pulse — SPEC

Монитор сети Arc без серверной части: статичный `index.html` на GitHub Pages читает RPC прямо из браузера.
Сервер лишь шлёт «пинг»-транзакции (ончейн-замер) и пишет журнал. Сначала тестнет (5042002), мейннет (5042) — только вместе с пользователем.

## Конфиг
`config.json`: сети `testnet`/`mainnet` → chainId, список RPC, адрес контракта пинга. Ключ только /etc/agent/arc.key (в репо не попадает).

## Пункты (с проверкой — по PLAN §2)
- **P-1 Блоки/время/финализация.** Дашборд показывает высоту, среднее время блока (окно 50 блоков), finalized vs latest по каждому RPC. *Проверка:* checker берёт блоки у 2 других провайдеров, допуск ±2 блока, ±0,1 с.
- **P-2 Согласованность RPC.** Таблица провайдеров: высота, задержка, chainId, статус; расхождение > 2 блоков подсвечивается. *Проверка:* checker сравнивает.
- **P-3 Цена транзакции.** Газ (eth_gasPrice/feeHistory) и стоимость простой tx в USDC. *Проверка:* = фактически уплаченному в последнем пинге (±5%).
- **P-4 Активность.** tx/блок и tx/с за окно. *Проверка:* пересчёт по сырым блокам.
- **P-5 Контракт-пинг.** `Pinger.sol` (v3): `ping(sentAtMs, prevLatencyMs)` только от владельца; кольцо последних 32 пингов
  (sentAtMs, blockNumber, blockTimestamp, prevLatencyMs), `recent()` отдаёт их одним вызовом; событие `Ping`. `ping.py` шлёт tx раз в 10 мин
  (systemd `arc-pulse-ping.timer`), журнал `data/pings-<net>.jsonl` (hash, блок, задержка отправка→квитанция, комиссия), потолок $0,20/сут.
  В сеть пишется измеренная задержка ПРЕДЫДУЩЕГО пинга (block.timestamp в секундах — грубо при блоке 0,5 с).
  *Проверка:* квитанция у другого RPC; комиссия = изменение баланса; не-владелец получает revert; задержка в сети = журнал.
- **P-6 Дашборд читает пинги** через `recent()` (без диапазонов логов: у dRPC окно < 1000 блоков), комиссию — из квитанции
  (лог в одном блоке → tx → gasUsed × effectiveGasPrice). *Проверка:* `check_ui.py` — то, что на экране, = контракт, квитанции, журнал.
- **P-7 Отказ провайдера.** Мёртвый RPC (подставляется `?addrpc=`) на экране «down», остальные «ok» и цифры верны. *Проверка:* `check_ui.py`.
- **P-8 Безопасность.** Нет ключей в репо (`make check` ищет), мейннет-запись блокируется флагом `ALLOW_MAINNET=1`.
- **P-9 Доступность.** Pages открывается снаружи; CORS у всех RPC.
- **P-10 (второй шаг) x402**: бесплатный хостинг функций; без оплаты 402, оплата EIP-3009 — 200; повтор подписи отказ.

## Проверка
`make check`: синтаксис, сборка контракта, поиск ключей, `checker.py` (сеть против сети), `check_ui.py` (живая страница в браузере против сети;
проверен подлогами — неверное время блока, комиссия ×0,9, «мёртвый» провайдер не помечен — все ловятся).
